# Blogging-Platform

A full-stack **Blogging Platform** built using the **MERN Stack** that allows users to create, manage, and interact with blog posts through a secure authentication system.

## Features

* User authentication with **Register**, **Login**, and **Reset Password**.
* Create and publish new blog posts.
* View recently uploaded blog posts on the home page.
* Manage your own posts by **editing**, **deleting**, and **viewing** them.
* Like and comment on blog posts.
* Secure logout functionality.

## Tech Stack

* **Frontend:** React.js
* **Backend:** Express.js & Node.js
* **Database:** MongoDB Atlas
* **HTTP Client:** Axios API
* **Authentication:** JWT-based user authentication

## Project Overview

The frontend is developed using **React.js**, while the backend is built with **Express.js** and **Node.js**. **Axios** is used to communicate between the frontend and backend APIs, and **MongoDB Atlas** is used as the cloud database to securely store user accounts, blog posts, likes, and comments. The application provides a responsive and user-friendly interface for creating, managing, and interacting with blog content.
